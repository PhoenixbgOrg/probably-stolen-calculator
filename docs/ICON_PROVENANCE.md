# Icon provenance

Tiles in `public/icons/` are **original purpose-based SVG symbols** drawn in this repository. They are **not game sprites**.

## What is claimed

- Each profession, perk, and chemist-kit name has a documented **name reference URL** (wiki or walkthrough page).
- Each tile is a calculator symbol whose geometry follows the documented **purpose** of that name.
- Every rendered tile is labeled **Not a game sprite**.

## What is not claimed

- These are **not** authentic in-game icons.
- Individual in-game artwork was **not** copied, traced, or renamed.
- Appearance versus the game sprite is **unverified**.
- Wiki access and CC BY-SA wiki **text** are not a license to reuse game icons, screenshots, or CDN images.
- No official Questing Goose / tinyBuild fan-kit license was found (2026-11-07).

## Mapping

See `src/data/iconManifest.ts`. Permission for authentic artwork is `none-found` on every row. `individualArtworkUrl` is null.
