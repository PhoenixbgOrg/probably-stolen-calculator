An underfilled Cartel delivery with some goods is not by itself an immediate Retired trigger. Required purity can change, so the default 10% cutoff is not permanent. Inspectors, fake inspectors, grace and crime-value calculations follow Security rules. A reactor stopping power at integrity 25 also differs from exploding at 0.
Assassinated and No Permit have ending display data, but their ordinary trigger paths have not been established in this build; display text alone is not a confirmed route.
End-of-day order
Night processing handles reactors before health. Health can already display Sentinel Collapse, but processing continues afterwards.
The remaining night systems run and the new day begins.
A reactor explosion flag takes the Meltdown branch; otherwise Augmented is checked. Only if neither branch applies does this point call automatic saving.
Thus the reactor branch precedes Augmented here. Sentinel does not guarantee an early stop and can be followed by saving or another ending display. Opening-time reputation threats also use independent checks; static evidence does not establish a universal ending priority.

Return to menu / quit
These buttons do not make an additional save. The ending display itself does not automatically delete the slot
Retention limits saved records/files, not one guaranteed file for each calendar day. Main files are 
save_<slot>.es3
, the index is 
saves_index.es3
, and histories are 
save_<slot>_day<day>_<timestamp>.es3
. The actual system directory must be checked on the local machine.
Loading and preserving branches
Select a slot on the load screen, expand its history list and choose an existing historical save.
Loading history keeps the same slot; later saves update that slot. Use slot duplication first to preserve an independent branch. History-file copy failures can leave an incomplete copied history.
The load screen also supports renaming, orphan-file discovery and confirmed deletion. Deletion handles the main file, index and recorded histories.

A historical file disappears between selection and scene loading

The main file is absent when clicked or actually loaded
This path clears the slot and indexed histories; it is not a universal automatic-recovery path
Input/output failures receive at most four attempts, with a 150 ms delay before each retry. Failed writes also try restoring the just-rotated save; certain other errors can quarantine damaged files and rewrite or rebuild the index. These branches do not guarantee complete recovery from every failure.
