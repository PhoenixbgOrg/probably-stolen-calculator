Points and slots

The current new-game sequence is occupation → perks → difficulty and options. Perks are disabled on the first run. Later starts must pass all checks when continuing:

CheckRequired condition
PointsSum of signed perk costs ≤3; negative costs offset positive costs
SlotsSelected count ≤4 plus all selected extra slots; 0-cost perks still use one slot
IncompatibilityA declaration on either side blocks the pair

Selections may temporarily exceed a limit; Continue performs validation. Colorful Character is neutral, costs +1, occupies a slot and adds 3 slots, raising the total limit to 7. Category is not determined by cost sign.

Application order

OrderSettlement
1Initialize base state and activate the selected perk list; Minimalist/Ascetic change inventory dimensions, and substance-addiction timers initialize
2Place Hoarder's blocking debris before starting stock
3Grant occupation stock, change occupation cash/rent and apply occupation reputation changes; then process inputs for Sentinel, addictions and the welfare introduction
4If skipping the introduction, unlock the relevant introductions/services and grant documents/tools, keeping Rock Bottom and perk-specific exclusions
5Apply remaining starting effects: cash, rent, direct reputation changes, tapes, toolbox, reactor, luck, vending machine and others; then save the new run

Selected perks already affect persistent checks during occupation-stock initialization. Ordinary occupation reputation changes first receive Blabbermouth, Sycophant, difficulty and other applicable modifiers. Perks' own direct starting reputation adjustments occur afterward.

Initial values and stock

Let C be cash after the career adjustment and R be its first current rent, both in Credits:

  • Starting cash = C + 150 when Savings is selected.
  • First current rent = R + 40 for Bad Lease + 75 for Prime Real Estate. Both can apply; later rent changes belong to Shop Management.

These are perk-specific modifiers. The complete trade, fee, faction, health and security rules remain in their respective topics.

The explicitly rounded integer stages use nearest-integer rounding with midpoint ties to even. Intermediate rounding matters, so consecutive percentage modifiers cannot simply be added. Ordinary reputation itself can retain fractions; this rounding rule does not cover every reputation operation.

Substance-use timers increase nightly and can naturally remove their corresponding perk at 20; narcotic withdrawal additionally checks its relief timer. Sentinel's 7/10/14-day thresholds, disease pool, treatment and full addiction state rules belong to Health, Wounds and Addiction. See Trade Calculations and Inspection, Wilds Network and Security and Permits for their shared rules.

Secret Admirer

Processed when opening the shutter in the morning. Day 2 attempts to grant one Galaxy Blend, resets the missed-roll counter and immediately returns, skipping random tapes, main gifts and notes.

Welfare Program

Processed when opening on days congruent to 1 modulo 7. Secret Admirer runs first, so successfully placed owned gifts may affect the same opening's welfare valuation.

Let cash be C and the game's total estimated value be T. Adjusted wealth is W = C + trunc((T−C)/3), dividing as an integer toward zero before adding cash. T includes cash and the trade estimates of eligible owned items in the main inventory, both counters, display, document area, trash inventory and both vending areas. Container valuation may include children, while locked items and other cases can be excluded. It is not a simple sum of catalog base values or all assets.

Gambling Addiction's compulsive purchases

Only qualifying customer-owned items successfully placed on the front counter through direct selling trigger this rule; barter is excluded. Lottery tickets have one counter. Single scratch tickets and scratch-ticket stacks share another counter. Both reset for a new customer; only successful purchases increment them. Failed attempts can be retried by the next qualifying item, with at most 5 successful purchases per category per customer.

ItemFixed amount deducted per purchase (Credits)
Lottery ticket25
Single scratch ticket20
Scratch-ticket stack100

Let P be the fixed price of the current item. The check uses the cash remaining at that moment:

Already bought in this category from this customerCurrent cash thresholdPurchase chance after threshold passes
0≥P100%
1≥2P50%
2≥5P40%
3≥10P30%
4≥25P20%
≥5—No more purchases

The threshold is not a price multiplier. Success deducts only P, marks the item owned and attempts to move it to the back counter, without asking for trade confirmation. Winning, redemption and the other gambling rules belong to Shop Management.

Hoarder

Before occupation stock, the game attempts to place rest, tool and service debris piles at the bottom of the main inventory. They cannot be moved directly. A failed preset placement falls back to ordinary placement.

PileClearing conditionProgress output
Rest pile10 nights without an actual outing; an outing pauses that night without resetting progress, so the nights need not be consecutiveEach qualifying night attempts 1 Scrap Metal and 1 ordinary Dumping Ground draw to the back counter
Tool pileUse a crowbar, wire cutter and plasma cutter on this pile once each; both tool and pile must be owned; each tool ID counts onceEach tool is destroyed; attempts 3 Common Electronic Parts, Wire and Scrap Metal respectively to the main inventory; third distinct tool clears the pile immediately
Service pile10 nights with the unlocked debris-removal service enabled; outings do not pause itBase service fee 50 Credits per active night, with 5 ordinary Dumping Ground draws to the back counter

Clearing any pile additionally makes 5 ordinary Dumping Ground draws and 5 draws excluding ordinary junk. The tool pile sends clearing output to the main inventory; the other two use the back counter. A completing overnight pile grants that night's progress output before clearing output. Draws can be empty and placement can fail, so this is not a promise of 10 items. Full loot tables belong to Afterhours and Scavenging.

Mind-editing boundaries

RuleResult
Editable set16 definitions; normal UI can add only the 5 positive ones; existing editable negative/neutral perks can only be removed
Points and slotsDoes not reapply the 3-point/4-slot starting budget; still checks incompatibility both ways
Careful ScavengerCan be removed with 0 charge and 0 new cooldown after any old cooldown finishes; normal UI cannot add it back
Minimalist / AsceticRemoval restores the main inventory to 24×10 and validates its contents
Substance addictionsAdding/removing resets relevant timers; past losses are not refunded
Other persistent effectsLater calls check the current list; no universal rollback of settled rewards, reputation or events, and no guarantee of instantly refreshed existing quotes

Device edits are immediate and closing the window does not undo them. See the Mind Reprogrammer for the complete list, charge costs, per-device cooldown and acquisition.

Blackmail demands 40 + current day Credits. Refusal or arrest removes the perk and passes −30 to each of the four existing Lower Levels, Revolution, Security and Upper Levels reputation records, subject to reputation modifiers. The code also calls −30 for Neural Church, but this build does not create that reputation record in a new run, so that call has no actual reputation effect. Visits, choices and original dialogue belong to Characters and Visitors. Sawyer's Crew unlocks the Underground Exchange only when its introduction finishes. Janitorial fee is 0 without vandalism; after vandalism it is trunc(day/5) + 30, with Black Market distrust still able to double it. Full service rules belong to Shop Management.
